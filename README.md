# Плагіни Nukkit

У репозиторії є два незалежні Maven-проєкти:

- `math-plugin/` - математичні завдання українською мовою.
- `subserver-plugin/` - запуск і зупинка підсерверів.

Стандартна структура підсервера:

```text
plugins/subserver/subservers/subserver1/nukkit-1.0.jar
```

Після встановлення JAR підсерверного плагіна в `plugins/` команда `/ss start subserver1` запускає саме цей файл. Збірка:

```bash
mvn -f math-plugin/pom.xml package
mvn -f subserver-plugin/pom.xml package
```

Готові JAR знаходяться в `math-plugin/target/` і `subserver-plugin/target/`.

Команди підсерверного плагіна:

- `/ss start <назва>` - запуск із уже підготовленої папки `plugins/subserver/subservers/<назва>/`.
- `/ss startmain <назва>` - запуск із копією JAR основного сервера у власну `plugins/` підсервера.
- `/ss stop <назва>` - ручна зупинка.
- `/ss m <назва> <команда>` - команда в консоль підсервера.
- `/ss list` - список підсерверів.

Підсервери зберігаються в папці даних підсерверного плагіна. Вони зупиняються під час вимкнення основного сервера або через `/ss stop`; таймера автогасіння за бездіяльністю немає.
